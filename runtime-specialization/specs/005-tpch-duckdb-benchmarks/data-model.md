## Runtime Entities

### TPC-H Databases

| Entity | Path (default) | Format | Lifetime |
|--------|---------------|--------|---------|
| SQLite TPC-H DB | `tpch/data/tpch.db` | SQLite | Persistent on disk; generated by `generate.py` |
| DuckDB TPC-H DB | `tpch/data/tpch.duckdb` | DuckDB | Persistent on disk; generated by `generate.py` |
| Results DB | `benchmarks/benchmarks.duckdb` | DuckDB | Persistent; managed by `record_benchmark.py` |

The three files are always distinct. `generate.py` writes only to the TPC-H databases and never touches the results database.

### DuckDB Connection Model

Per benchmark function (opened and closed around each `benchmark::State` loop):

```
duckdb_database  ──open──▶  duckdb_connection  ──prepare──▶  duckdb_prepared_statement
                                                                       │
                                                               specializeOnly()
                                                                       │
                                                               duckdb_execute_prepared(stmt, &g_result)
```

- `duckdb_database`: file handle; one per benchmark function
- `duckdb_connection`: query context; one per benchmark function
- `duckdb_prepared_statement`: compiled query plan; one per query per function; **the specialization argument**
- `g_duckdb_exec_result`: module-level static `duckdb_result`; address baked into specialized function; destroyed and reused between loop iterations

### SQLite Connection Model (unchanged)

```
sqlite3*  ──open──▶  sqlite3_stmt* / Vdbe*  ──specializeOnly──▶  sqlite3VdbeExec(vdbe)
```

## Benchmark Group Schema

### Group Name Mapping

| Old name | New name | Engine |
|----------|----------|--------|
| `tpch` | `db/sqlite3/tpch` | SQLite |
| (none) | `db/duckdb/tpch` | DuckDB |

### Benchmark Name Format

```
BM_g:<group>;n:<kernel>;t:<phase>;
```

Examples after this feature:
```
BM_g:db/sqlite3/tpch;n:tpch_q1;t:unspecialized;
BM_g:db/sqlite3/tpch;n:tpch_q1;t:jit_overhead;
BM_g:db/sqlite3/tpch;n:tpch_q1;t:specialized_exec;
BM_g:db/sqlite3/tpch;n:tpch_q1;t:p1_specialized_exec;
BM_g:db/sqlite3/tpch;n:tpch_q1;t:jit_analysis;
BM_g:db/duckdb/tpch;n:tpch_q1;t:unspecialized;
BM_g:db/duckdb/tpch;n:tpch_q1;t:jit_overhead;
BM_g:db/duckdb/tpch;n:tpch_q1;t:specialized_exec;
BM_g:db/duckdb/tpch;n:tpch_q1;t:jit_analysis;
```

Queries: `tpch_q1` through `tpch_q22` (22 per group).

### Phase Definitions

| Phase | SQLite | DuckDB | Notes |
|-------|--------|--------|-------|
| `unspecialized` | `sqlite3_step()` loop | `duckdb_execute_prepared()` | Baseline; MinTime(1.0) |
| `jit_overhead` | `specializeOnly(vdbe)` × 1 | `specializeOnly(stmt, &g_result)` × 1 | JIT compile cost; Iterations(1) |
| `specialized_exec` | specialized fn loop | specialized fn loop | Execution cost; MinTime(1.0) |
| `p1_specialized_exec` | pipeline-1 opts | (TBD — may add later) | Alt pipeline; MinTime(1.0) |
| `jit_analysis` | `benchmarkJITAnalysis` | `benchmarkJITAnalysis` | Pass-trace JSON; UseManualTime() |

### Counters Emitted (per benchmark run)

Inherited from existing infrastructure (populated by `phaseJITOverhead`):
- `jit_module_fns`, `jit_module_instrs`, `jit_blob_kb`
- `jit_pruned_fns`, `jit_pruned_instrs`
