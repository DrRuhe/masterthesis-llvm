# Implementation Plan: JIT Specialization Core

**Branch**: `WIP-specialization/benchmarking/fix-TCPH-q1` | **Date**: 2026-04-26 | **Spec**: `specs/003-jit-specialization-core/spec.md`

## Summary

Spec 003 describes the existing JIT specialization engine. The engine is almost entirely implemented; the only remaining delta is a significant simplification of `prepareModuleForJIT`: once spec 004 (IR Dump Preprocessing) ships, all JIT-time linkage fixup is eliminated and the function reduces to a single `ExternalLinkage` assignment on the wrapper. This plan covers that simplification and its prerequisite.

## Technical Context

**Language/Version**: C++17, LLVM/Clang (in-tree build)  
**Primary Dependencies**: LLVM ORC JIT, LLJITBuilder, PassBuilder, GlobalDCE, JITLink  
**Storage**: N/A

**Project Type**: In-process JIT library  
**Performance Goals**: Per-call `prepareModuleForJIT` cost reduced to O(1) (single loop iteration for wrapper) vs. O(functions + globals) currently  
**Constraints**: All 18 smoke tests MUST remain green; no regression in benchmark correctness

### Phase 1 — Simplify `prepareModuleForJIT`

**File**: `runtime/ClangRuntimeSpecializer/ClangRuntimeSpecializer.cpp`

Replace the entire body of `prepareModuleForJIT` (currently lines 695–816, ~120 lines) with:

```cpp
void ClangRuntimeSpecializer::prepareModuleForJIT(llvm::Module& M,
                                                   const std::string& WrapperName) const {
  // All linkage invariants (InternalLinkage for functions, WeakODRLinkage for
  // vtable globals, absence of llvm.global_ctors/dtors and zero-sized globals)
  // are established at compile time by IRDumpingPass (spec 004).
  // The only JIT-time task is to expose the wrapper as the sole entry point.
  auto *Wrapper = M.getFunction(WrapperName);
  assert(Wrapper && "wrapper must exist before prepareModuleForJIT");
  Wrapper->setLinkage(llvm::GlobalValue::ExternalLinkage);
}
```

**Also update** the comment at line ~449 (inside the IR transform lambda) from:
> `// Safe: prepareModuleForJIT already gave the wrapper ExternalLinkage and vtable`  
> `// functions WeakODRLinkage (both are GlobalDCE roots).`

to:
> `// Safe: IRDumpingPass set vtable functions to WeakODRLinkage at compile time`  
> `// (spec 004); prepareModuleForJIT set the wrapper to ExternalLinkage.`  
> `// Both are GlobalDCE roots.`
