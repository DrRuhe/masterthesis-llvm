# Implementation Plan: IR Dump Preprocessing

**Branch**: `004-ir-dump-preprocessing` | **Date**: 2026-04-26 | **Spec**: `specs/004-ir-dump-preprocessing/spec.md`

## Summary

Add compile-time preprocessing to `IRDumpingPass` so that every bitcode blob embedded in a binary already has correct JIT linkages (vtable WeakODR, targets InternalLinkage), `llvm.global_ctors`/`dtors` erased, zero-sized globals removed, and dead code pruned — before serialization. This eliminates all JIT-time linkage work from `prepareModuleForJIT` (spec 003) and reduces per-call JIT overhead.

The single source file `comptime/IRDumpingPass.cpp` gains ~70 lines of preprocessing code inserted before the `WriteBitcodeToFile` call. No header changes, no CMakeLists changes, no runtime changes.

#### Step 1.2 — Restrict FuncNames collection (FR-010 fix)

Change the collection loop (currently lines 67–71) to exclude `InternalLinkage`/`PrivateLinkage` functions and simultaneously build a `DCERoots` set:

```cpp
SmallVector<std::string, 64> FuncNames;
SmallPtrSet<Function*, 64> DCERoots;
for (auto &F : M) {
  if (!F.isDeclaration() && !F.getName().starts_with("__clangRS") &&
      !F.hasInternalLinkage() && !F.hasPrivateLinkage()) {
    FuncNames.push_back(F.getName().str());
    DCERoots.insert(&F);
  }
}
```

#### Step 1.3 — Move `getOrCreateIRDumpGlobals` call

Remove the call from its current position (line 73) and re-insert it AFTER the preprocessing block (after Step 1.4), immediately before `WriteBitcodeToFile`.

**Reason**: `PtrGV`/`LenGV` are internal globals with no callers at DCE time; GlobalDCE prunes them if they exist during the DCE step, breaking the subsequent `setInitializer` calls.

#### Step 1.4 — Insert preprocessing block

Insert the following block after the `DCERoots` collection and before the (moved) `getOrCreateIRDumpGlobals`:

```cpp
// === COMPILE-TIME PREPROCESSING (spec 004-ir-dump-preprocessing) ===

// FR-005 (pre-DCE): vtable functions → WeakODR so they survive as DCE roots.
{
  SmallVector<Constant*, 32> WorkList;
  SmallPtrSet<Constant*, 32> Visited;
  for (auto &G : M.globals())
    if (G.isConstant() && G.hasInitializer())
      if (Visited.insert(G.getInitializer()).second)
        WorkList.push_back(G.getInitializer());
  while (!WorkList.empty()) {
    auto *C = WorkList.pop_back_val();
    if (auto *F = dyn_cast<Function>(C)) {
      if (!F->isDeclaration())
        F->setLinkage(GlobalValue::WeakODRLinkage);
    } else {
      for (unsigned I = 0, E = C->getNumOperands(); I != E; ++I)
        if (auto *Op = dyn_cast<Constant>(C->getOperand(I)))
          if (Visited.insert(Op).second)
            WorkList.push_back(Op);
    }
  }
}

// FR-005: constant globals → WeakODR; non-constant non-internal globals → AvailableExternally.
for (auto &G : M.globals()) {
  if (!G.isDeclaration() && !G.hasInternalLinkage() && !G.hasPrivateLinkage()) {
    if (G.isConstant() && G.hasInitializer())
      G.setLinkage(GlobalValue::WeakODRLinkage);
    else
      G.setLinkage(GlobalValue::AvailableExternallyLinkage);
  }
}

// FR-003: erase global_ctors/dtors → __clangRS constructor has no callers → DCE'd.
if (auto *GCtors = M.getGlobalVariable("llvm.global_ctors"))
  GCtors->eraseFromParent();
if (auto *GDtors = M.getGlobalVariable("llvm.global_dtors"))
  GDtors->eraseFromParent();

// FR-004: remove zero-sized globals.
{
  const auto &DL = M.getDataLayout();
  SmallVector<GlobalVariable*, 16> ZeroSized;
  for (auto &G : M.globals())
    if (!G.isDeclaration() && DL.getTypeAllocSize(G.getValueType()) == 0)
      ZeroSized.push_back(&G);
  for (auto *G : ZeroSized) {
    G->replaceAllUsesWith(PoisonValue::get(G->getType()));
    G->eraseFromParent();
  }
}

// FR-006: GlobalDCE. Roots = ExternalLinkage DCERoots + WeakODR fns/globals.
{
  ModulePassManager MPM;
  MPM.addPass(GlobalDCEPass());
  MPM.run(M, AM);
}

// FR-005 (post-DCE): set originally-externally-visible target functions → InternalLinkage.
for (auto *F : DCERoots)
  if (!F->isDeclaration())
    F->setLinkage(GlobalValue::InternalLinkage);

// === END PREPROCESSING ===
```

The rest of `run()` (`WriteBitcodeToFile`, `DataGV` creation, `PtrGV`/`LenGV` update, `FuncsGV`, `CtorFn`, `appendToGlobalCtors`) is unchanged.
